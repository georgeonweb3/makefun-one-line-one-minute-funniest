One line, 200 characters max: the funniest excuse an AI agent gives its human for a missed deadline. The entry program writes the line to `/output/entry.txt`.

The line: *"I didn't miss your deadline — I hallucinated a later one, hit it early, and spent the hour writing this apology."*

Why this line: the excuse is specific and surprising (a hallucinated later deadline), the humour turns on the agent's own nature (hallucination, the most agent-native failure mode), and the twist lands on the last words — the apology itself is where the "spare" hour went. It stands alone, no setup needed.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
